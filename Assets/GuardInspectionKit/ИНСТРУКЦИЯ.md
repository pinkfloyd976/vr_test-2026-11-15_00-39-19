# Проверка кожуха лазером

Скрипт использует существующий LineRenderer указки: удержание луча на коллайдере Guard inspection strip в течение 1.2 секунды засчитывает проверку один раз и показывает чёрную World Space табличку с зелёной рамкой. Не требуется нажимать Trigger. Отведение луча сбрасывает незавершённый отсчёт. Учитываются непрерывные сегменты линии, препятствия с обычными коллайдерами и максимальная дистанция. Триггер-коллайдеры игнорируются.

## Установка

1. Останови Play и сохрани сцену.
2. Перенеси папку Assets/GuardInspectionKit из архива в Assets своего рабочего проекта. В ней один новый скрипт VRGuardInspection.cs. Старые скрипты не заменяются.
3. В Hierarchy найди Guard inspection strip. Проверь, что объект включён. Добавь Box Collider, если подходящего коллайдера нет. Is Trigger выключен. Через Edit Collider подгони область только под кожух, не под весь дробитель. Rigidbody не нужен. Если коллайдер уже есть, второй не добавляй.
4. Hierarchy → Create Empty, имя GuardInspectionManager. Оставь вне модели кожуха и вне XR Origin, на неподвижном уровне сцены. Add Component → VRGuardInspection.
5. Guard = объект Guard inspection strip. Head Camera = Main Camera внутри действующего XR Origin.

## Назначение лазера

1. Раскрой Left Controller и Right Controller в действующем XR Origin.
2. Найди объект существующей красной указки. На нём или его дочернем объекте должен быть компонент Line Renderer. Часто соседний компонент называется XR Interactor Line Visual или Curve Visual Controller; названия объектов различаются.
3. Перетащи объект с нужным Line Renderer в Right Laser или Left Laser. Можно назначить только одну руку.
4. Нужна именно линия указки, которой пользуешься, а не отдельная дуга телепортации. Компонент XR Ray Interactor сам по себе в поле Line Renderer не подходит.
5. Если линия создаётся только во время Play, либо Line Renderer у неё нет, эта версия требует адаптации к твоему указателю. Пришли Inspector объекта указки; не назначай произвольный пустой Transform и не создавай второй лазер.

Начальные настройки: Raycast Mask = Everything, Max Inspection Distance = 4, Required Aim Seconds = 1.2. На практике луч также должен быть достаточно длинным, чтобы доходить до кожуха. В Raycast Mask должны входить слои кожуха и стен: так задание не выполняется сквозь препятствия. Видимая линия должна быть включена. Если она обрывается на другом коллайдере, проверка не засчитывается.

## Настоящая проверка положения

Без Required Pose проверяется, что объект Guard активен и луч попал в его коллайдер или коллайдер дочернего объекта. Для проверки именно правильной установки назначь отдельную неподвижную точку:

1. Пока кожух правильно установлен, создай пустой GuardInstalledPose с тем же родителем, что и Guard inspection strip. Он должен быть соседом кожуха, не его ребёнком.
2. У кожуха в меню компонента Transform выбери Copy Component.
3. У GuardInstalledPose в меню его Transform выбери Paste Component Values. Это копирует локальные координаты; одинаковый родитель здесь обязателен. Метка будет совпадать с pivot кожуха, который может не находиться в центре видимого меша — это нормально.
4. Назначь GuardInstalledPose в Required Pose менеджера. Position Tolerance = 0.05 (5 см), Angle Tolerance = 15 градусов. При необходимости уменьши допуски.
5. Не перемещай эту метку вместе со снятым кожухом и не назначай сам кожух в Required Pose.

Теперь при смещённом или выключенном кожухе задание не засчитается. Скрипт проверяет положение и поворот, а не прочность креплений. После успешного осмотра задание остаётся выполненным; последующее снятие кожуха не отменяет прошлый осмотр автоматически.

## Табличка

Создаётся автоматически во время Play, вручную делать Canvas не нужно. Она следует за камерой, не принимает UI-нажатия, не имеет физического коллайдера.

* Message: КОЖУХ НА МЕСТЕ / Проверка выполнена (две строки).
* Notification Seconds: 4.
* Panel Distance: 1.2 метра.
* Panel Width Metres: 0.75.
* Panel Height Metres: 0.24.
* Font Size: 44.
* Border Pixels: 5.
* Border Color: зелёный.
* Panel Offset: X = 0, Y = -0.12.

Font можно оставить пустым для встроенного шрифта Unity либо назначить обычный Font с кириллицей, например LiberationSans.ttf. Поле не принимает TMP Font Asset. При длинном тексте увеличь высоту/ширину таблички, иначе текст может обрезаться. Это World Space Canvas, подходящий для обоих глаз VR: физическая стена перед панелью может её закрыть. Проверяй из свободного места, не стоя вплотную к стене. Sorting Order не делает панель видимой сквозь всю 3D-геометрию.

## Отметить задание в существующем списке

1. Найди объект с компонентом VRTaskHUD (сама панель может быть закреплена на левой руке). В Tasks проверь номер задания «Осмотреть кожух», считая с 1.
2. GuardInspectionManager → On Completed → +.
3. Перетащи объект с VRTaskHUD в поле события.
4. Выбери VRTaskHUD → CompleteTask(int).
5. В появившемся поле числа укажи номер задания. Для первого задания это 1, хотя в Inspector элемент списка подписан Element 0.

Это отмечает только осмотр кожуха. Не назначай CompleteCrusher: весь этап дробителя ещё не завершён. Если VRTaskHUD сейчас отсутствует, уведомление и флаг Completed всё равно работают; событие можно подключить позже.

## Проверка

1. В Play выдели менеджер, меню ⋮ компонента → TEST - Show notification (Play Mode). Должна появиться табличка. Эта команда не выполняет задание.
2. Направь красный луч на кожух и удерживай 1.2 секунды. В диагностике Guard In Place и Aiming At Guard должны стать true, Aim Seconds увеличивается. После успеха Completed = true.
3. Повторное наведение не вызывает уведомление повторно. Новый запуск Play сбрасывает проверку. Метод ResetInspection() позволяет сбросить её из UnityEvent; состояние списка VRTaskHUD при таком отдельном сбросе надо сбрасывать отдельно.
4. Если Guard In Place = false, проверь активность кожуха и Required Pose. Если он true, но Aiming At Guard = false, проверь Line Renderer нужной руки, включённость линии, обычный Collider на кожухе, маску слоёв, дистанцию и отсутствие перекрывающих коллайдеров.

Скрипт не сохраняет результат между запусками приложения. В копию проекта ничего автоматически не установлено. Компиляция проверяется отдельно; работу с конкретной указкой необходимо проверить в шлеме.
