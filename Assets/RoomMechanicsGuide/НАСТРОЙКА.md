# Настройка комнат, автоклава и гайковёрта

Инструкция подготовлена по сохранённой сцене `Assets/Scenes/SampleScene_Repaired.unity` и скриптам проекта `C:\UNITY PROJECTS\vr_test`. Сам проект не изменён. Проверены файлы, а не работа сцены в шлеме; несохранённые изменения открытого Unity сюда не входят.

## 1. Что уже есть в проекте

Четыре кнопки используют один компонент `CrusherLevelButton`, но с разными Stage. Это допустимо: название класса не ограничивает назначение кнопки.

| Кнопка | Stage | Destination |
|---|---|---|
| ДРОБИЛЬНИК | Crusher | Spawn_Crusher |
| АВТОКЛАВ | Autoclave | Spawn_Autoclave |
| НАСОС | Pump | Spawn_Pump |
| РАЗГРУЗКА ЖИДКОГО СТЕКЛА | LiquidGlass | Spawn_LiquidGlass |

Эти назначения уже записаны в сцене. Назначены Teleportation Provider и обе точки рук; радиус касания 0.04 м, время удержания контакта 0.18 с. То есть контроллер нужно коснуться и ненадолго задержать — нажимать Grip не нужно. В `VRStageProgress` включено `Unlock All Teleports For Testing`: сейчас порядок прохождения не блокирует переходы.

У дробителя в файле сцены сохранились `CrusherMotorController`, AudioSource, ссылка на аудиоклип и две `VRPanelTouchButton`. События кнопок направлены на `StartMotor` и `StopMotor`, точки рук — `ButtonPusherLeft` и `ButtonPusherRight`. Поэтому утверждать, что все скрипты удалились, нельзя. После замены модели нужно проверить, что сохранённые компоненты относятся именно к видимым кнопкам нового дробителя, а их зоны касания совпадают с кнопками. Поле AudioSource Clip пустое само по себе не ошибка: контроллер назначает клип при запуске.

В сцене есть старый `ImpactWrench` с `VRImpactWrench` и `WallMountedTool`. Его размер головки в настройках — 36. В сцене обнаружены три старых компонента `VRThreadedNut`; это ещё не настройка всех новых гаек автоклава.

В проекте два FBX автоклава, оба встречаются в сохранённой сцене:

* `Autoclav/Автоклав 1.fbx`: внутри `шурупы` восемь отдельных мешей `Cylinder.016`–`Cylinder.023`; внутри `Empty` восемь болтов `Cylinder`–`Cylinder.007`.
* `Autoclav/Автоклав.fbx`: внутри `шурупы` один меш `Cylinder.030`; здесь же есть `rubber.003`.

Для восьми независимых гаек используй вариант `Автоклав 1`. Один объединённый меш не позволит существующему скрипту вращать отдельные гайки. `rubber.003` можно вынести из второго экземпляра и использовать отдельно. Не удаляй весь родительский объект с нужными деталями.

## 2. Установка трёх новых скриптов

1. Останови Play.
2. Сохрани сцену: Ctrl+S. Желательно сделай копию через File → Save As.
3. Распакуй архив рядом с проектом.
4. Перенеси папку `RoomMechanicsAdditions` из папки `Assets` архива в окно Project → Assets в Unity.
5. Дождись компиляции. Старые скрипты не удаляй и не заменяй.

В папке три файла:

* `RoomTeleportAction.cs` — действие телепортации, которое вызывает кнопка.
* `AutoclaveRotation.cs` — вращение и плавная остановка.
* `AutoclaveNutSetup.cs` — настройка существующей `VRThreadedNut` по двум точкам в редакторе.

Они используют твои уже существующие компоненты. Это не отдельный проект Unity.

## 3. Проверка четырёх кнопок меню

1. В Hierarchy выбери `ДРОБИЛЬНИК`.
2. В Inspector найди `Crusher Level Button` и сверь Destination с таблицей выше. Повтори для остальных кнопок.
3. Если ссылки пустые, перетащи нужные объекты из Hierarchy в поля.
4. В Teleportation Provider перетащи объект рига с компонентом `Teleportation Provider`: обычно `XR Origin (XR Rig) → Locomotion → Teleportation`.
5. Для точного касания можно вместо центров контроллеров назначить `ButtonPusherLeft` и `ButtonPusherRight` в Left/Right Touch Point. Эти объекты уже есть внутри рук. Поставь их в месте, которым хочешь касаться кнопки, например на переднем конце модели контроллера.
6. Выбери каждую Spawn-точку и расположи её **на поверхности пола, на уровне стоп**, а не головы. Синяя стрелка Z задаёт направление взгляда после перехода. Точка не должна находиться внутри стены, оборудования или зоны кнопки возврата.
7. Проверь, что на полу каждой комнаты есть Collider и `Is Trigger` выключен. Иначе после телепортации игрок может провалиться.
8. В Play коснись кнопки и задержи контроллер примерно на четверть секунды.

Если не переносит: в меню компонента кнопки нажми `Test Teleport` в Play. Если тест срабатывает — проверяй зону Press Area и точки рук. Если не срабатывает — Console, Destination, Provider, его Mediator и активность XR Origin. Не добавляй второй XR Origin в каждую комнату: для одной сцены нужен один активный риг.

## 4. Универсальная физическая кнопка

Этот шаблон пригодится для возврата и автоклава. Кнопка срабатывает от касания контроллером, а видимая часть немного уходит назад. Это анимация касания, не симуляция силы пальца.

1. Hierarchy → правая кнопка → Create Empty. Назови `ReturnButton_Crusher`.
2. У корня оставь Scale `(1,1,1)`. Перемести его на удобную высоту около 1.1–1.3 м от пола.
3. Правая кнопка на корне → 3D Object → Cube. Назови дочерний куб `Cap`.
4. У Cap поставь Local Position `(0,0,0)`, Local Rotation `(0,0,0)`, Scale `(0.18,0.18,0.04)`.
5. У Cap удали только компонент Box Collider через меню ⋮ → Remove Component.
6. На корне нажми Add Component → Box Collider. Center `(0,0,0)`, Size `(0.18,0.18,0.06)`, включи Is Trigger.
7. На корне Add Component → `VRPanelTouchButton`.
8. В Press Area перетащи корень (его Box Collider), в Press Visual — Cap.
9. Разверни Touch Points, Size = 2. Element 0 = `ButtonPusherLeft`, Element 1 = `ButtonPusherRight`.
10. Touch Radius = `0.025`, Release Margin = `0.01`, Press Travel = `0.01`, Animation Speed = `0.08`.
11. Local Press Direction = `(0,0,1)`. Разверни корень так, чтобы синяя стрелка +Z шла от игрока внутрь стены. Тогда +Z означает вдавливание. Если лицевая сторона направлена иначе, поменяй Z на `-1`.

Передвигай и поворачивай весь корень, а не один Cap: так зона нажатия останется на месте кнопки. Чтобы увеличить кнопку, меняй Scale у Cap и Size у корневого Box Collider согласованно.

Можно добавить надпись: дочерний 3D Text - TextMeshPro, текст «В МЕНЮ», повернуть к игроку и поставить перед лицевой плоскостью. При запросе TMP Essentials нажми Import. Надпись не нужна для срабатывания кнопки.

## 5. Кнопки возврата из всех комнат

1. Hierarchy → Create Empty → имя `Spawn_Menu`.
2. Поставь его на пол в начальной комнате в свободном месте перед меню; поверни синюю стрелку в сторону меню. Не ставь внутрь кубов телепортации.
3. На `ReturnButton_Crusher`, созданный по разделу 4, добавь `RoomTeleportAction`.
4. Destination = `Spawn_Menu`.
5. Teleportation Provider = тот же объект Teleportation из XR Origin, что используется четырьмя кнопками меню.
6. У `VRPanelTouchButton` раскрой On Pressed → нажми `+`.
7. В пустое поле события перетащи `ReturnButton_Crusher`.
8. В выпадающем списке No Function выбери **RoomTeleportAction → Teleport()**.
9. Выдели корень и Ctrl+D три раза. Назови копии `ReturnButton_Autoclave`, `ReturnButton_Pump`, `ReturnButton_LiquidGlass`.
10. Перемести по одной копии в остальные комнаты. Destination всех четырёх — `Spawn_Menu`.
11. Проверь каждую копию: On Pressed должен ссылаться на её собственный RoomTeleportAction.

Не добавляй к этим кнопкам `CrusherLevelButton`: возврат не должен зависеть от прохождения этапа. Не оставляй одновременно два скрипта, которые самостоятельно обрабатывают касание одной кнопки.

## 6. Восстановление кнопок дробителя и звука

Сначала выясни, перестало ли работать касание или само включение звука.

1. В Hierarchy раскрой **новый** дробитель. Найди мотор `55 kW electric motor body`.
2. Выбери его. Если `CrusherMotorController` уже есть, используй его. Если отсутствует — Add Component → CrusherMotorController; AudioSource добавится автоматически.
3. В Motor Sound назначь свой зацикленный звук из Assets. Volume `0.65`, Min Distance `1`, Max Distance `20` — начальные значения, которые можно менять.
4. Найди видимую зелёную кнопку `Cabinet_lamp_g_1` и красную `Cabinet_lamp_g_1.001`. Проверь цвета в сцене: после импорта суффиксы могут не означать тот же цвет.
5. На каждой проверь `VRPanelTouchButton`: Press Area = Box Collider **этой кнопки**, Press Visual = её видимая подвижная часть, Touch Points = две точки ButtonPusher.
6. В On Pressed зелёной кнопки оставь одну рабочую запись: перетащи **новый мотор** → CrusherMotorController → StartMotor(). У красной — StopMotor(). Удали устаревшие записи Missing и лишние вызовы.
7. В Play выбери зелёную кнопку → ⋮ в заголовке VRPanelTouchButton → **Test Press (Play Mode Only)**.

Если тест запускает звук, скрипт мотора и событие работают. Тогда причина обычного нажатия находится в зоне касания или точках рук:

* В Scene включи Gizmos, выдели кнопку. Жёлтая рамка должна охватывать именно лицевую поверхность кнопки.
* В Box Collider нажми Edit Collider и подгони рамку к новой модели. Она должна выступать перед панелью на несколько миллиметров, а не быть спрятанной внутри корпуса.
* У импортированных объектов необычные масштабы. В сохранённой сцене Size кнопки очень мал в локальных координатах; без учёта масштаба модели это не доказывает ошибку. Ориентируйся на видимую рамку в Scene, а не копируй число вслепую.
* В Play Active Touch Points должно быть 2. Nearest Distance Metres должен уменьшаться при приближении руки. При значении меньше Touch Radius должно включиться Is Pressed.
* Для пробы Touch Radius можно поднять до `0.025`. Не расширяй зоны настолько, чтобы одним касанием нажимались обе кнопки.

Если тест не запускает звук: проверь Console, Motor Sound, активность мотора и компонента, Mute у AudioSource, наличие включённого AudioListener на камере. Для диагностики выставь Min Distance `3` и подойди к мотору. Spatial Blend текущий контроллер устанавливает сам при старте.

Для продавливания попробуй Press Travel `0.01` и Animation Speed `0.08`. Направление зависит от локальных осей **новой** кнопки; поменяй знак нужной оси, если она движется наружу. Настройки прежнего меша могут не подходить.

Если компоненты старой кнопки после замены модели отображаются Missing или находятся на невидимой детали, создай отдельный корень и Cap по разделу 4. Вместо нового куба Cap можно использовать настоящий меш кнопки: перенеси его под корень, сохранив положение в сцене. Старый VRPanelTouchButton отключи, чтобы одна кнопка не вызывала событие дважды.

## 7. Автоклав: общий центр вращения

Не добавляй независимое вращение на корпус, люк и гайки. У всех должен быть один общий вращающийся родитель.

1. Найди экземпляр автоклава рядом со `Spawn_Autoclave`. Для отдельных гаек используй `Автоклав 1`.
2. Если Unity запрещает менять иерархию внутри импортированной модели: на её корне правая кнопка → Prefab → Unpack Completely. Это разрывает связь этого экземпляра с FBX, но не удаляет модель из Assets. Работай с копией сцены.
3. Создай пустой объект на верхнем уровне Hierarchy: `AutoclavePivot`. Scale `(1,1,1)`.
4. Поставь его точно в центр оси, вокруг которой должен крутиться корпус. В Scene переключи сверху Center на Pivot и режим стрелок Global/Local на Local.
5. Я трактую вращение как вращение барабана вокруг его продольной горизонтальной оси. Поверни AutoclavePivot так, чтобы его синяя стрелка +Z проходила вдоль этой оси через центр корпуса и люка.
6. Перетащи под AutoclavePivot объекты `2`, `3`, `Empty`, `шурупы`. Обычное перетаскивание в Hierarchy сохраняет их мировое положение. **Не нажимай Reset на деталях после переноса**.
7. Не переноси вместе с ними забор, пол, площадку, опоры, кнопки и гайковёрт. Они должны оставаться неподвижными.
8. Добавь на AutoclavePivot `AutoclaveRotation`.
9. Local Axis `(0,0,1)`, Speed Degrees Per Second `25`, Acceleration `15`, Deceleration `10`.

Если под «по горизонтали» ты имел в виду поворот всего аппарата влево/вправо вокруг вертикали, создай неповёрнутый Pivot в нужном центре и поставь Local Axis `(0,1,0)`. Это другое движение; остальные настройки те же.

На вращающихся деталях отключи Static. У них не должно быть независимых динамических Rigidbody, Animator или скриптов, которые одновременно задают им позицию. Скрипт вращает Transform; если позже нужна полноценная передача сил физическим предметам от вращающегося аппарата, это потребует отдельной настройки Rigidbody/коллайдеров.

## 8. Кнопка включения/выключения автоклава

1. Создай кнопку по разделу 4. Назови `AutoclavePowerButton`.
2. Поставь рядом с панелью управления, **вне AutoclavePivot**.
3. В VRPanelTouchButton → On Pressed → `+`.
4. Перетащи `AutoclavePivot` в поле события.
5. Выбери **AutoclaveRotation → ToggleRunning()**.

Первое касание запускает, второе останавливает. Между касаниями отводи руку от кнопки. При скорости 25 и Deceleration 10 торможение длится примерно 2.5 секунды. Корпус продолжит немного вращаться во время торможения и останется в достигнутом положении; возврата в начальный угол нет. Чтобы торможение было быстрее, увеличь Deceleration.

Двигай весь `AutoclavePowerButton`, его область касания переместится вместе с ним. Для проверки без шлема в Play воспользуйся Test Press на VRPanelTouchButton.

## 9. Новый гайковёрт rubber.003

Можно использовать уже существующие скрипты: новый отдельный контроллер гайковёрта не нужен.

1. Вне AutoclavePivot создай пустой корень `AutoclaveWrench`, Scale `(1,1,1)`.
2. Поставь корень в удобную точку инструмента, например центр рукоятки. Перенеси `rubber.003` внутрь, сохранив положение модели. При необходимости сначала распакуй её экземпляр Prefab.
3. На корень добавь Rigidbody: Mass `1.5`, Use Gravity включён, Is Kinematic выключен, Interpolate = Interpolate. Состояние на креплении далее контролирует WallMountedTool.
4. Добавь Box Collider на корпус и отдельный Box/Capsule Collider на рукоятку, подгони под форму. Is Trigger выключен. Не используй в движущемся гайковёрте невыпуклый Mesh Collider; проще составить форму из примитивов.
5. На корень добавь **XR Grab Interactable**, Movement Type = Kinematic, Select Mode = Single. Для предсказуемого отпускания выключи Throw On Detach. Interaction Layer Mask выставь как у старого работающего ImpactWrench.
6. В списке Colliders у XR Grab Interactable явно укажи все физические коллайдеры нового инструмента.
7. Создай под корнем пустой `GripPoint` и поставь на рукоятку в место хвата. Назначь его в Attach Transform. Положение/поворот GripPoint настрой проверкой в руке; для первого теста можно включить Use Dynamic Attach, чтобы брать в точке контакта.
8. Добавь на корень `VRImpactWrench`.
9. Создай под корнем пустой `SocketTip`. Поставь его в точку, которая при надевании головки должна совпадать с лицевой точкой гайки. **Синяя стрелка SocketTip +Z направлена от инструмента к гайке, внутрь люка**.
10. Socket Tip = этот SocketTip. Socket Size MM = `36`, Turns Per Second = `2`, Engagement Distance = `0.025`, Alignment Angle = `20`.
11. Rotating Socket назначай только если головка инструмента — отдельная деталь с осью Z вдоль головки. Если `rubber.003` — цельный меш, оставь поле пустым: гайки будут работать, но головка визуально вращаться не будет. Не назначай весь гайковёрт в Rotating Socket.
12. Direction Indicator необязателен. Можно назначить отдельный небольшой MeshRenderer-индикатор; зелёный означает закручивание, красный — откручивание.

Управление существующего скрипта: Grip — взять; Trigger — работать; A на правой руке или X на левой — сменить направление. После смены направления отпусти и нажми Trigger заново. Это **не Y**. На активном Direct/Near-Far Interactor должен быть правильно указан Handedness Left/Right; Activate должен быть привязан к Trigger. Сохрани работающие настройки рук от старого гайковёрта.

## 10. Гравитация, подсветка и место хранения

1. На AutoclaveWrench добавь существующий `WallMountedTool`.
2. В меню ⋮ этого компонента выбери **Setup: создать зону на стене и материал контура**.
3. Появится отдельный `WrenchWallMount`, а в Mount Point будет ссылка на него.
4. Размести гайковёрт так, как он должен висеть. На WallMountedTool выбери **Зона: поставить в текущую позицию гайковерта**.
5. Snap Radius = `0.15`, Snap Duration = `0.15`, Return Delay = `5`, Outline Width начни с `0.002`.
6. Outline Renderers можно оставить пустым — скрипт найдёт меши внутри нового инструмента. Если назначаешь вручную, выбирай Renderer именно rubber.003.

WrenchWallMount не должен быть дочерним объектом инструмента или вращающегося автоклава. В Play инструмент сначала окажется на креплении. Когда подносишь руку достаточно близко для XR-hover, появится контур. При захвате контур пропадёт. Если отпустить вне зоны — инструмент упадёт и примерно через 5 секунд свободного состояния вернётся на крепление; приближение руки при hover приостанавливает этот таймер. Если отпустить в зоне — встанет на место сразу с короткой анимацией.

Не добавляй второй XRSocketInteractor на это же крепление: WallMountedTool уже сам выполняет фиксацию. `VRWrenchDrop` к новому инструменту тоже не нужен — WallMountedTool сам обнуляет скорость при отпускании и включает гравитацию. Под инструментом должен быть пол с обычным Collider, чтобы он не проваливался.

## 11. Настройка каждой гайки по двум точкам

В `Автоклав 1 → шурупы` есть восемь отдельных мешей. Сначала настрой одну гайку и проверь её, затем повтори для остальных. Автоматически сопоставлять Cylinder.016 с конкретным болтом по номеру не надо — найди пару визуально.

Для каждой пары нужна структура:

```
AutoclavePivot
  2
  3
  Empty                     ← неподвижные относительно люка болты
  шурупы
    NutRoot_01              ← центр оси выбранного болта
      NutVisual             ← пустой объект с центром на оси гайки
        Cylinder.016        ← настоящий меш одной гайки
        ContactPoint
      SeatedMarker
      LooseMarker
    NutRoot_02
      ...
```

1. Пока Play выключен, поставь первую гайку в полностью закрученное положение у люка. Не сбрасывай Transform импортированного меша.
2. Внутри `шурупы` создай пустой `NutRoot_01`. Поставь его на ось выбранного болта, в центре гайки. Направь его синюю стрелку +Z **от люка наружу вдоль болта**. Это противоположное направление стрелке SocketTip гайковёрта.
3. Внутри NutRoot_01 создай пустой `NutVisual`: Local Position `(0,0,0)`, Local Rotation `(0,0,0)`, Local Scale `(1,1,1)`.
4. Перенеси только соответствующий меш гайки внутрь NutVisual. Не нажимай Reset: гайка должна остаться на своём месте. Этот пустой объект даёт ей правильный центр вращения, даже если исходный pivot меша был далеко.
5. Внутри NutVisual создай `ContactPoint`. Поставь его на оси гайки с наружной стороны, где находится точка контакта с головкой инструмента. Он будет перемещаться вместе с гайкой.
6. Внутри NutRoot_01, рядом с NutVisual, создай `SeatedMarker` и `LooseMarker`. Не делай их детьми NutVisual.
7. SeatedMarker поставь точно в центр **NutVisual** в полностью закрученном положении, не на поверхность люка. Если NutVisual в локальном нуле, SeatedMarker тоже `(0,0,0)`.
8. LooseMarker передвинь только по локальной Z наружу: его положение означает, где окажется **центр NutVisual**, когда гайка почти у конца болта. Оставь запас резьбы, чтобы гайка не сходила с болта. X и Y у обоих маркеров должны совпадать.
9. На NutRoot_01 добавь `AutoclaveNutSetup`. `VRThreadedNut` добавится автоматически.
10. Назначь четыре ссылки Nut Visual, Contact Point, Seated Marker, Loose Marker. Total Turns = `6`, Socket Size MM = `36` — как у гайковёрта.
11. В меню ⋮ компонента AutoclaveNutSetup нажми **Apply markers to VRThreadedNut**. Это записывает настройку в существующий компонент; в Play вспомогательный скрипт ничего не перемещает.
12. Сохрани сцену. В начале игры гайка будет затянута, откручивание ограничится LooseMarker, закручивание — SeatedMarker.

После перемещения маркеров снова нажимай Apply. Маркеры задают положение центра одной и той же гайки, а не две поверхности её меша. Не добавляй на гайку XR Grab Interactable или динамический Rigidbody: её положение задаёт резьба. Scale у новых корней и их родителей желательно `(1,1,1)`, без отрицательных и неравномерных масштабов. Масштабировать сам импортированный меш внутри NutVisual можно.

Если на гайке есть физический Collider, который не даёт подвести головку, используй отдельный слой гаек и отключи столкновения только пары «гайковёрт–гайки» в Physics Layer Collision Matrix, либо убери ненужный Collider гайки. Поиск гайки в VRImpactWrench геометрический: коллайдер ему не нужен. Столкновения гайковёрта с полом оставь.

Проверь первую гайку: инструмент должен быть взят, удерживается Trigger, размеры Socket Size MM совпадают, обе точки сближены до Engagement Distance, оси направлены навстречу. Меняй направление A/X, затем снова нажимай Trigger. Когда это работает — повтори настройку для оставшихся семи гаек.

Все NutRoot и маркеры находятся под AutoclavePivot, поэтому после поворота аппарата сохранят правильные позиции относительно люка. Люк, болты и гайки не должны отдельно вращаться скриптом автоклава вокруг собственных центров.

## 12. Проверка по очереди

1. Из меню коснись каждой кнопки и проверь, что попал в нужную комнату на пол.
2. В каждой комнате коснись возврата: оказываешься у Spawn_Menu, без немедленного повторного телепорта.
3. Дробитель: зелёная кнопка нажимается и запускает звук, красная останавливает; после отпускания кнопки возвращаются.
4. Автоклав: первое касание включает общее вращение, второе плавно останавливает. Люк не уезжает относительно корпуса.
5. Гайковёрт: берётся, подсвечивается при hover, падает на пол и возвращается, фиксируется после отпускания в зоне.
6. Каждая гайка вращается отдельно, доходит до обоих ограничений и после поворота автоклава по-прежнему работает.

Три новых скрипта проверены компилятором с библиотеками твоего Unity 6000.6.7f1 и установленного XRI в вариантах Editor и Player. Испытание в шлеме и точная подгонка осей/коллайдеров ещё нужны. Автоматическое завершение этапов здесь не добавляется: критерии правильного прохождения остаются отдельной задачей.
