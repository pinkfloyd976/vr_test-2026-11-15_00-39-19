# VR-взаимодействия для Unity 6 / XR Interaction Toolkit 3.6.1

Комплект подготовлен для проекта vr_test: версия XRI 3.6.1 проверена в Packages/manifest.json. Семь скриптов скомпилированы против библиотек установленного Unity 6000.6.7f1 и проекта. Проверка поведения в шлеме не выполнялась.

## 1. Установка и общие правила

1. Выйди из Play Mode. Сохрани сцену, желательно сделай её копию.
2. Перенеси папку Scripts из этого комплекта в Assets/VRInteractions. Дождись компиляции. Имена файлов менять не нужно.
3. Твои XR Origin, XR Interaction Manager, передвижение и Direct Interactor остаются основой сцены.
4. Создавай каждый механизм через GameObject → Create Empty. У корневых объектов оставляй Scale = (1,1,1); размеры меняй у дочерних моделей. Все размеры ниже в метрах.
5. Добавляй компоненты через Add Component. Ссылку в поле Inspector заполняй перетаскиванием нужного объекта из Hierarchy.
6. Interaction Layer Mask у Interactable и контроллеров должен иметь общий слой. Для начала можно использовать Default. Это отдельная настройка от обычного GameObject Layer, используемого физикой.
7. У всех захватываемых объектов в примерах Select Mode = Single. На одном объекте не должно одновременно быть XR Simple Interactable и XR Grab Interactable.
8. У интерактивных деталей оставляй Collider включённым. Для динамических Rigidbody используй Box/Sphere/Capsule Collider либо выпуклый Mesh Collider (Convex).

## 2. Вентиль — захват и вращение кистью

Создай иерархию:

    ValveBase                 неподвижная основа
      ValvePivot              центр вращения
        Wheel                 видимая модель + Collider

Для проверки Wheel может быть Cube размером (0.25, 0.04, 0.04): получится небольшая рукоятка. Центр Wheel совпадает с ValvePivot. Настоящую модель вентиля можно подставить позже.

На ValvePivot добавь:

- Rigidbody: Use Gravity выключено, Is Kinematic включено.
- XR Simple Interactable: Select Mode = Single. В Colliders добавь коллайдер Wheel явно.
- VRValve: Local Axis = (0,0,1), Min Angle = 0, Max Angle = 720, Angle = 0.

Ось Z (синяя стрелка локальных осей) должна проходить вдоль штока вентиля. Если модель смотрит иначе, поверни ValveBase целиком или укажи другую Local Axis.

Поднеси контроллер, удерживай обычную кнопку захвата и поворачивай кисть вокруг оси штока. Вентиль вращается только вокруг заданной оси. Можно отпустить, вернуть кисть и перехватить. 720 градусов — два оборота. Если нужен четвертьоборотный кран, поставь Max Angle = 90.

On Value Changed выдаёт число от 0 до 1. Его можно подключить к своему компоненту управления потоком. Для первичной проверки смотри изменение Angle в Inspector во время игры. Это управляемое вращение, без расчёта момента силы и сопротивления вентиля.

## 3. Дверь — физическая петля и ручка

Создай отдельный Empty Door, его Position — у нижнего края двери со стороны петель. Scale = (1,1,1), Rotation = (0,0,0).

    Door                      ось петель
      Panel                   Cube
      Handle                  Cube

Пример двери шириной 0.9 м и высотой 2 м:

- Panel: Local Position = (0.45,1,0), Local Scale = (0.9,2,0.04). Оставь Box Collider.
- Handle: Local Position = (0.78,1,0.09), Local Scale = (0.12,0.04,0.10). Оставь Box Collider.
- Поставь Door в сцене так, чтобы низ полотна не пересекал пол. У Panel и Handle не должно быть своих Rigidbody.

На Door добавь:

- Rigidbody: Mass = 5, Use Gravity выключено, Is Kinematic выключено, Interpolate = Interpolate, Collision Detection = Continuous Dynamic. Constraints не замораживать: ограничение создаёт петля.
- Hinge Joint: Connected Body пусто (крепление к миру), Anchor = (0,0,0), Axis = (0,1,0), Use Limits включено, Limits Min = 0, Max = 110. Use Spring и Use Motor выключены.
- XR Simple Interactable: Select Mode = Single. В Colliders оставь только коллайдер Handle. Полотно продолжает физически сталкиваться с окружением, но захват выполняется за ручку.
- VRDoor: Handle = объект Handle. Остальные значения сначала оставь по умолчанию.

Возьми ручку и веди руку по дуге. Скрипт прикладывает ограниченную силу к ручке, Hinge Joint удерживает дверь на петлях. Если направление открывания получилось обратным, используй Limits Min = -110, Max = 0. При слишком большом отдалении руки захват автоматически снимается.

XR Grab Interactable на Door не добавляй: он будет пытаться переносить полотно к руке и конфликтовать с петлёй. Если дверь дрожит, сначала исключи пересечения полотна с полом/рамой, затем уменьши Stiffness или увеличь Damping в VRDoor.

## 4. Кнопка — нажатие касанием без Grip

В этой реализации движение колпачка вычисляется по глубине касания. Это физический жест нажатия, но не симуляция пружины через Rigidbody.

Под каждым отслеживаемым контроллером создай Empty ButtonPusher. Размести его на переднем конце модели контроллера — там, где хочешь нажимать кнопку. Для настройки можно добавить дочернюю Sphere диаметром 0.024 м и удалить у неё Collider. У самих ButtonPusher Collider и Rigidbody не нужны. Важно: они должны следовать именно за контроллерами, а не за общим XR Origin.

Создай кнопку:

    ButtonRoot
      Base
      Cap
      Surface

Начальный пример — кнопка на горизонтальной поверхности, нажимается вниз:

- ButtonRoot: Scale = (1,1,1), Rotation = (0,0,0).
- Base: Cube, Local Position = (0,-0.015,0), Scale = (0.14,0.03,0.14).
- Cap: Cylinder, Local Position = (0,0.02,0), Scale = (0.09,0.01,0.09). Стандартный цилиндр Unity имеет высоту 2, поэтому верх колпачка здесь на Y = 0.03.
- Surface: Empty, Local Position = (0,0.03,0). Он обозначает верх ненажатой кнопки и НЕ должен быть дочерним Cap.
- У Cap удали Collider: нажатие здесь определяет скрипт. Base может иметь обычный Box Collider.

На ButtonRoot добавь VRPressButton:

- Cap → объект Cap.
- Surface → объект Surface.
- Pushers: Size = 2; перетащи левый и правый ButtonPusher.
- Pusher Radius = 0.012, Button Radius = 0.045, Travel = 0.025.
- Return Speed = 0.12.

Приближай кончик контроллера к колпачку и продавливай его. Нажатие срабатывает на 90% хода; повторное возможно после возврата ниже 30%. Для установки на стену поверни ButtonRoot целиком: его локальная зелёная ось +Y всегда должна смотреть из панели наружу.

Проверка события: создай Point Light с именем TestLamp, отключи его GameObject. В On Pressed нажми +, перетащи TestLamp, выбери GameObject → SetActive(bool), включи галочку аргумента. Теперь нажатие включает свет. Если нужен свет только пока кнопка удерживается, в On Released добавь тот же SetActive с выключенной галочкой. Скрипт не требует XR Simple/Grab Interactable на кнопке.

## 5. Шланг — совмещение, отпускание, фиксация

В комплекте реализован захватываемый наконечник и его подключение. Гибкое тело шланга, натяжение, коллизии всей трубки и поток жидкости сюда не входят. Для первого теста достаточно одной модели наконечника.

    HoseEnd
      Model
      MatingPoint

На HoseEnd добавь:

- Rigidbody: Use Gravity включено, Is Kinematic выключено, Interpolate = Interpolate.
- XR Grab Interactable: Select Mode = Single, Movement Type = Kinematic, Track Position и Track Rotation включены, Use Dynamic Attach выключено, Throw On Detach выключено.
- HoseConnector: Connector Type = Water, Mating Point → объект MatingPoint.

Model — например Cube размером (0.04,0.04,0.12) с Box Collider. В Colliders у XR Grab Interactable укажи этот Collider. MatingPoint поставь на конце модели, например Local Position = (0,0,0.06). В XR Grab Interactable поле Attach Transform тоже заполни MatingPoint. Это важно: точка проверки совмещения должна совпадать с точкой привязки при защёлкивании.

Создай отдельное гнездо:

    HoseSocket
      SocketPoint
      SocketVisual

На HoseSocket:

- Sphere Collider: Is Trigger включено, Radius = 0.08. Центр области расположи у SocketPoint.
- AlignedHoseSocket. Это уже наследник XR Socket Interactor; второй XR Socket Interactor не добавляй.
- Attach Transform → SocketPoint.
- Accepted Type = Water, Max Distance = 0.04, Max Angle = 15.
- Hover Socket Snapping выключено, Show Interactable Hover Mesh выключено, Socket Active включено.
- Interaction Layer Mask должен пересекаться со слоем HoseEnd. Для нескольких типов предметов удобно завести отдельный interaction layer Hose и включить его также у Direct Interactor рук.

SocketVisual — декоративная модель без перекрывающего отверстие коллайдера. Не ставь сплошную стенку прямо на место, куда должен войти наконечник.

Ориентация: в итоговом соединении локальные стрелки MatingPoint и SocketPoint должны смотреть одинаково, в том числе синяя +Z и зелёная +Y. Разворачивай точки привязки отдельно от моделей, если визуально соединения должны смотреть навстречу друг другу.

Возьми наконечник, совмести точки ближе 4 см и с отклонением меньше 15 градусов, затем отпусти Grip. Только после отпускания Socket сможет выбрать объект. Он зафиксирует наконечник своей привязкой. Чтобы снять, снова возьми наконечник рукой и отведи от гнезда. Отводи до следующего отпускания, иначе гнездо снова его подхватит.

События Select Entered и Select Exited на AlignedHoseSocket можно подключить к индикатору подключения. Порог проверяется только при новом соединении; после соединения гнездо сохраняет выбранный наконечник.

## 6. Осмотр предметов

Новый скрипт не требуется. На уже захватываемом предмете проверь XR Grab Interactable: Track Position = On, Track Rotation = On. Для свободного захвата в текущем месте включи Use Dynamic Attach, Match Position и Match Rotation, если эти поля доступны. Затем приближай предмет к голове и вращай контроллер.

Это отдельная рекомендация для обычных предметов осмотра. У наконечника шланга оставь фиксированную привязку из предыдущего раздела. Не отключай коллайдеры всем предметам ради осмотра. Если они исчезают вплотную к лицу, не подноси их внутрь Near Clip Plane камеры; менять эту настройку для базового взаимодействия не нужно.

## 7. Инструмент — пример электрической отвёртки

    Screwdriver
      Model
      Tip

На Screwdriver добавь Rigidbody и XR Grab Interactable, как у твоего рабочего захватываемого куба. У Model должен быть Collider; Tip — Empty на рабочем конце отвёртки. На Screwdriver добавь VRTool:

- Tool Type = Screwdriver.
- Tip → объект Tip.
- Radius = 0.025.

Создай Cube Screw размером примерно 0.03 м — это тестовый винт. Оставь Box Collider и добавь ToolTarget:

- Required Tool = Screwdriver (строка должна совпадать).
- Seconds To Complete = 2.

Создай обычный физический Layer ToolTarget через Inspector → Layer → Add Layer. Назначь его объекту Screw. В VRTool → Target Layers отметь ToolTarget. Это GameObject Layer, а НЕ Interaction Layer Mask из XRI. Если у цели коллайдер дочерний, слой назначь именно объекту коллайдера.

Возьми отвёртку, поднеси Tip к винту и удерживай Activate. Обычно это Trigger, но фактическая кнопка зависит от Input Actions твоего контроллера. Скрипт получает стандартные события Activated/Deactivated от XR Grab Interactable. Если захват работает, а применение нет, проверь назначение Activate Input у Interactor контроллера.

Две секунды суммарного контакта активным инструментом вызовут On Completed. Для теста подключи его к TestLamp → GameObject.SetActive(true), как у кнопки. On Progress выдаёт 0…1. Завершение происходит один раз, до вызова ResetProgress(). При уходе от винта прогресс сохраняется.

Это конкретный пример применения инструмента по типу, контакту и времени. Он не моделирует резьбу, крутящий момент, работу гаечного ключа или силу удара молотка — для них нужны отдельные правила.

## 8. Проверка по порядку

1. Console не содержит ошибок компиляции.
2. Вентиль вращается кистью, сохраняет положение после отпускания и останавливается на ограничениях.
3. Дверь держится на петле; захватывается ручка, а не всё полотно.
4. Кнопка срабатывает без Grip; удержание не создаёт повторных On Pressed.
5. Шланг с неверным типом или направлением не подключается; выровненный подключается после отпускания и снимается рукой.
6. Предмет осмотра следует позиции и повороту руки.
7. Инструмент без Activate не работает; активный инструмент работает только возле подходящей цели.

Сначала проверяй по одному механизму в XR Device Simulator, затем в шлеме. Для вентиля отдельно проверь вращение контроллера: вращение камеры/HMD не является вращением кисти.
