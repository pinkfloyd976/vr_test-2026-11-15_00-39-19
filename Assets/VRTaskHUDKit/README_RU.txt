VRTaskHUDKit v2 — панель по кнопке Y

ОБНОВЛЕНИЕ:
1. Останови Play и сохрани сцену.
2. В Unity: правой кнопкой по Assets/VRTaskHUDKit > Show in Explorer.
3. Из архива скопируй папку VRTaskHUDKit прямо в Assets с заменой существующих файлов. НЕ удаляй старую папку и .meta. НЕ создавай копии скриптов с суффиксом 1.
4. Вернись в Unity, дождись компиляции.
5. Выдели существующий VR_TaskHUD в Hierarchy.
6. GameObject > VR Mechanics > Upgrade Selected HUD to Y Panel.
7. Ctrl+S. Задания и текст безопасности сохраняются; оформление заменяется новыми начальными настройками.
8. В Play панель изначально скрыта. Нажми Y на левом контроллере Quest 2.

УПРАВЛЕНИЕ:
Y — показать / скрыть. При каждом открытии панель появляется слева перед текущим положением головы.
Поднеси руку к темному фону, зажми боковую кнопку Grip, перемещай и вращай контроллер. Можно брать любой рукой. Отпусти Grip — панель останется на месте. Повторное Y работает и во время захвата.
Панель больше не следует за головой: это отдельный предмет. Если оставил ее позади, скрой и снова открой через Y.

НАСТРОЙКИ:
Тексты остаются в VR Task HUD: Tasks / Safety Text.
Follow Camera оставь выключенным.
Task Font Size / Safety Font Size / Title Font Size — размер текста, начальные 80 / 72 / 76. Значения увеличены вместе с разрешением панели, чтобы буквы не были мелкими на текстуре.
Font Style — начальное Bold. Line Spacing — межстрочное расстояние.
Width — 1520, Metres Per Pixel — 0.0005: ширина примерно 76 см до ограничения высоты.
Maximum Height — 0.95 м. Очень длинный текст уменьшит всю панель: сокращай текст либо меняй ширину/высоту с проверкой в шлеме.
Background Color, A — непрозрачность, начальное 0.96.
В новом компоненте VR Grabbable Task Panel:
Open Offset X — положение левого края: ближе к нулю = правее.
Open Offset Y — положение верхнего края: меньше = ниже.
Open Offset Z — расстояние при открытии: начальное 0.65 м.
Show At Start — показывать при запуске, изначально выключено.
Grab Thickness — толщина области захвата в метрах.
Положение при открытии теперь настраивается через Open Offset, не через старые Distance / Top Left Offset.
В Edit Mode панель видна для настройки. В Play скрывается до нажатия Y.

ВАЖНО:
Не выключай сам объект VR_TaskHUD: компонент должен оставаться активным, чтобы считывать Y. Код скрывает только Canvas и захват.
Коллайдер — trigger, Rigidbody — kinematic, Use Gravity выключен, Throw On Detach выключен. Эти настройки выставляются меню автоматически. Панель не толкает игрока и другие предметы.
Материал обычный UI: руки видны перед панелью. Геометрия комнаты теперь может перекрыть панель; открывай ее на свободном месте.
Если рука не захватывает: у ее Direct/Near Interactor и у XR Grab Interactable панели должны пересекаться Interaction Layer Mask (генератор ставит Default). Используется существующий захват твоего XR Origin.
Y считывается отдельным Input Action: <XRController>{LeftHand}/secondaryButton. Это не отключает другие действия проекта на Y.
Изменения во время Play не сохраняются после Stop.

ПРОВЕРКА:
C# скомпилирован с библиотеками Unity 6000.6.7f1 и XR Interaction Toolkit 3.6.1 проекта: отдельно редакторские и игровые скрипты. В шлеме проверить: Y открывает один раз за нажатие; удержание Y не мигает; Grip захватывает; отпускание не бросает; Y во время захвата скрывает; следующее Y возвращает панель перед головой; длинный текст не перекрывает блок безопасности. Исполнение в шлеме здесь не проверялось.
